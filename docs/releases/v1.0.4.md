## Stability update

- Validates note data before writing it, so an invalid document cannot replace a readable notes file.
- Protects first-use migration of existing notes with an exclusive file lock.
- Adds a release check that launches a relocated app with isolated storage and confirms it stays running.
- Rechecks the universal app, bundled editor, MCP server, and disk image before publication.

Download `Notes-1.0.4-universal.dmg`, open it, and drag Notes to Applications. It supports Apple Silicon and Intel Macs running macOS 13 or newer. Existing local notes remain in place.

This developer preview is ad hoc signed and has not been notarized. macOS Gatekeeper may prevent it from opening after download. Developer ID signing and Apple notarization are required for a normal installation experience.
