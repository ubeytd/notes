## Startup fix

Notes now loads its editor from the installed app bundle instead of relying on Swift's generated resource lookup. The release build checks that path before publishing.

Download `Notes-1.0.3-universal.dmg`, open it, and drag Notes to Applications. It supports Apple Silicon and Intel Macs running macOS 13 or newer. Existing local notes remain in place.

This developer preview is ad hoc signed and has not been notarized. macOS Gatekeeper may prevent it from opening after download. A future build with Developer ID signing and Apple notarization is needed for a normal drag-to-install experience.
