## Live Markdown headings

Typing `# ` through `###### ` at the start of a paragraph now creates the matching heading immediately. Pressing Return in a heading continues in a normal paragraph, including when the cursor is in the middle of heading text.

The heading behavior is covered by an automated WebKit test in the release workflow. Existing notes and settings remain in place.

This developer preview is ad hoc signed and has not been notarized. macOS Gatekeeper may prevent it from opening after download. Developer ID signing and Apple notarization are required for a normal installation experience.
