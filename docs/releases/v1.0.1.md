## First developer preview

Notes is a local-first macOS writing app with a focused editor, Markdown formatting, searchable notes and actions, persistent themes, keyboard shortcuts, and a local MCP server.

### What is included

- App-wide hotkeys to create or browse notes from another application. Change or disable them in Settings.
- A first-run welcome window covering storage, shortcuts, and permissions.
- Universal Apple Silicon and Intel build for macOS 13 or newer.

### Install

Download `Notes-1.0.1-universal.dmg`, open it, and drag Notes to Applications. Verify the download with `shasum -a 256 -c Notes-1.0.1-universal.dmg.sha256` if desired.

### Signing status

This developer preview is ad hoc signed and has not been notarized. macOS Gatekeeper may prevent it from opening after download. A future build with Developer ID signing and Apple notarization is needed for a normal drag-to-install experience.

Notes are stored locally in `~/Library/Application Support/Notes/notes.json`. Existing data from the former folder is copied on first use. See the README for build instructions, shortcuts, and MCP setup.
