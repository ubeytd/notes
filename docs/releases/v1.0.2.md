## Install fix

This release fixes the resource bundle layout in the macOS app. Notes now opens correctly after it is moved to Applications or another folder.

Download `Notes-1.0.2-universal.dmg`, open it, and drag Notes to Applications. It supports Apple Silicon and Intel Macs running macOS 13 or newer. Verify the downloaded image with `shasum -a 256 -c Notes-1.0.2-universal.dmg.sha256` if desired.

The app includes local Markdown notes, themes, app-wide keyboard shortcuts, first-run onboarding, and a local MCP server. Existing notes are preserved.

This developer preview is ad hoc signed and has not been notarized. macOS Gatekeeper may prevent it from opening after download. A future build with Developer ID signing and Apple notarization is needed for a normal drag-to-install experience.
